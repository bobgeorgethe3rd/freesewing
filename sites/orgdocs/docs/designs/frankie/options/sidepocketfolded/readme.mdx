---
title: 'Side pocket folded'
---

Whether the side pocket is drafted by folding in half and turning inside out or the top is folded down.

- True the pocket is drafted so it is folded in half to create the pocket.
- False the pocket is drafted with a simple fold down top to create the pocket.

:::note

When [Side pocket pleat](../sidepocketpleat) is enabled this option is disabled.

:::
