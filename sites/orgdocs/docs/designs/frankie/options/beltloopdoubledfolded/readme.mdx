---
title: 'Belt loop double folded'
---

Whether the belt loop has to be folded in half or not.

- True the belt loops has to be folded in half
- False the belt loop does not have to be folded in half.

:::note

Whether you want this comes down to a few factors.

- Thickness of material

  - If you're material is very thick you may wish to omit the double fold as this can be quite bulky.

- If your material is proned to fraying
  - When double folded the raw edges are encased so it is more useful for those fabrics that tend to fray.

:::
