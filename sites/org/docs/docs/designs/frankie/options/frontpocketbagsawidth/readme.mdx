---
title: 'Front pocket bag seam allowance width'
---

Acts as a multiplier for the seam allowance of the front pocket bag independent from the default seam allowance.

:::note

This is useful if you need a larger seam allowance than default for finsihing such as _french_ or _flat-felled_ seams.
By default this is set at 1.5 to allow for _french seaming_.

:::
